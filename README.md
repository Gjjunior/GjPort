# 💻 Portfólio Pessoal | Gilmar Santos

Este projeto foi desenvolvido com o objetivo de praticar e aprimorar conhecimentos em Desenvolvimento Frontend utilizando HTML, CSS e JavaScript.

O site funciona como um portfólio pessoal, apresentando um pouco sobre minha trajetória profissional, habilidades, projetos e formas de contato.

---

# 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- DOM
- Flexbox
- Responsividade

---

# 🎯 Funcionalidades

✅ Alteração dinâmica de texto utilizando JavaScript e DOM  
✅ Alteração de tema do site  
✅ Cards interativos de projetos  
✅ Navegação suave entre seções  
✅ Links externos para GitHub e LinkedIn  
✅ Contato com e-mail e WhatsApp clicáveis  
✅ Layout responsivo  
✅ Animações e efeitos visuais
